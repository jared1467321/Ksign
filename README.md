# Ksign

Yet another codesigning app, have you ever wondered what if Feather and Esign had a child?

## Why?
Since Esign is end of service so people been moving to other signing apps, but Esign was a really big part of the community, so with the help of Feather as the base app, I tried to recreate Esign as close as possible so you guys can easier to get familiar and less app switching for smooth sideloading.

Another reason is this app was built specifically for Khoindvn to share his certificates, allowing more people to access to sideloading without even have to buy a certificate!

## Appearance

In **Settings → Appearance**, choose **System**, **Light**, or **Dark**.
The **Aurora Glass** theme combines the animated aurora and starfield from
Job Tracker with clear glass surfaces, including the title and search areas.
Both modes share the same clear glass finish, aurora shapes, and motion.
Light mode uses brighter, saturated aurora colors and dark text; dark mode uses
deeper aurora colors and frost-colored text.
Use **Shuffle Aurora** for a new sky, or turn off **Aurora Background** or
**Liquid Glass Surfaces** independently.

Native Liquid Glass requires iOS 26. Earlier versions use translucent material;
iOS 16 uses a static gradient instead of the Metal aurora. Reduce Motion freezes
the sky, and Reduce Transparency or Increase Contrast uses solid backgrounds
and surfaces. Animation pauses when the app leaves the foreground, and rendering
resolution adjusts to system load.

Duplicate Aurora Glass to edit its Light and Dark palettes independently.
Existing custom profiles retain their saved colors, and Halloween remains
available. The old built-in default switches to Aurora Glass once on upgrade;
an existing custom selection stays selected.

## Backup before reinstalling

In **Settings → Backup & Restore**, enter a backup password and choose
**Create Backup**. Save the `.asignbackup` file to iCloud Drive or another
location outside ASign. Files saved inside ASign are removed when the app is
deleted. You can choose the saved file and **Unlock Backup** to check your
password without restoring anything.

After installing a fresh copy, open **Backup & Restore**, choose that file,
unlock it with the same password, and select **Restore Backup**. The backup
includes certificate files, provisioning profiles, saved certificate passwords
and nicknames, the selected certificate, custom themes and their selected
profile, app settings, portable signing options, and source subscriptions.
Certificates and sources merge with the new installation; saved themes and
settings are applied immediately.

Backups use AES-GCM encryption with a password-derived key. The password is
not stored in the backup and cannot be recovered. Imported/signed app
libraries, archives, tweak files, container bookmarks, pending operations,
and device pairing are not included. Add tweak files and pair the device
again if needed after reinstalling.
